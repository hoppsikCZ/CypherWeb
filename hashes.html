Text hash generator

Generate a one-way digest from text with the browser's built-in Web Crypto API. Hashes cannot be decrypted.

About these hash functions

SHA-256

A widely used member of the SHA-2 family, suitable for integrity checks. Passwords should use a dedicated password-hashing algorithm instead.

SHA-384 and SHA-512

Two other SHA-2 variants that produce longer digests. SHA-512 has the largest output of the algorithms offered here.

SHA-1

An older hash with known collision weaknesses. Included for compatibility only; do not use it for security.
